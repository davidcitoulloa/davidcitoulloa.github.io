Sitio personal de David Ulloa (HTML + CSS + JS mínimo, sin build), publicado con GitHub Pages: https://davidcitoulloa.github.io

- **Textos:** `index.html`. El español va en el elemento; el inglés en su atributo `data-en` (y `data-en-alt` / `data-en-aria-label`).
- **Redes:** ver `REDES.md`.
- **Publicar:** `git add -A`, `git commit`, `git push` a `main`. Pages se actualiza en uno o dos minutos.
